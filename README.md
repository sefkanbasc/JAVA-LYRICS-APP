This project allows users to easily search for songs or artists.
The main functionality is as follows:

You can search by entering a song lyric or an artist's name into the search bar.

Click the Find button to view the search results.

If you want to see the full lyrics of a song, click the Lyric button.

Clicking on the artist's name will take you to a playlist page showing all songs by that artist.

You can refresh the page using the Reload button.

Use the Next button at the bottom to navigate to the next pages. (After clicking Next, the Prev button will also become active.)

Error handling has been implemented to ensure a smoother user experience.

How to Use
1. Type a song lyric or an artist's name into the search bar.

2. Click the "Find" button to search.

3. View the lyrics of the desired song or browse the artist's song list.

4. Use the reload or pagination buttons to refresh or navigate between pages.
